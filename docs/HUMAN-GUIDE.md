# 人类使用说明 · 游戏拆解与逆向分析师

## 这份岗位解决什么问题

在拥有授权的前提下，把录屏、截图、应用包、已有工程或 REA 证据整理成玩法、架构、规则、数值和资产结构，回答“它如何工作、我们观察到了什么、哪些仍然未知”。它帮助团队学习和做竞品判断，不把受保护素材直接变成我方资产。

## 30 秒开始

1. 指定目标版本、资料来源、授权范围和最想回答的问题。
2. 要求 Agent 先读 `SKILL.md`，再按目标选择路径：

   ```text
   npm ci --ignore-scripts
   python scripts/rea_bridge.py check
   python scripts/rea_bridge.py analyze-js examples/merge-fixture --out outputs/demo-analysis
   ```

3. 先看证据索引、覆盖范围和未知项，再看玩法/架构/资产视图。
4. 把我方要做的内容交给项目经理，把美术家族与样板交给 Art Director。

## 你需要提供

目标文件或工程、版本号、允许分析的范围、平台/引擎线索和问题清单。没有授权、没有目标文件或无法安装对应提供方时，应停在范围说明，不要通过猜测填空。

## 你会收到

五层拆解、证据 ID、文件哈希和位置、BOM、局限、待验证问题以及给项目经理的交接问题。REA 的 CLI 是静态分析入口；它不会运行目标游戏，也不等于恢复完整源码。

## 关键边界

- 只分析合法可用的材料；不绕过 DRM、支付、凭据、访问控制或在线服务。
- JS/Electron、APK、托管代码和原生程序需要不同提供方；某一入口成功不代表其他入口可用。
- 资产清单不等于制作工时，也不代表可以再分发原始素材。
- `observed`、`recovered`、`inferred`、`unknown` 必须分开。
